1. EXECUTIVE SUMMARY & ABSTRACT Section 1

Automation-CGI is an enterprise-grade, full-stack Warehouse Management System (WMS) engineered to solve the complex operational challenges of modern supply chain and fulfillment hubs. Combining a high-speed web and native desktop interface with an event-driven, layered REST backend and PostgreSQL database, the system governs the entire physical and transactional lifecycle of inventory items—from supplier procurement and multi-tiered Bill of Materials (BOM) management to physical warehouse slotting (Aisles, Racks, Bins), customer sales orders, and automated payment settlement.

Beyond standard warehousing operations, Automation-CGI incorporates an innovative Conversational Warehouse AI Engine with multi-turn context memory and hybrid rule/LLM tool dispatching, enabling warehouse personnel to query inventory health, stockouts, and order metrics in natural language. Equipped with interactive ECharts analytics (Heatmaps, Sankey flow diagrams, Gauges), live webcam/mobile QR code scanning, multi-tenant organization isolation, and PDF/Excel export engines, Automation-CGI represents a state-of-the-art solution designed for high throughput, sub-second latency, and rock-solid operational reliability.

2. PROBLEM STATEMENT & INDUSTRIAL MOTIVATION Section 2

Modern logistics centers manage tens of thousands of SKUs across fluctuating customer demands. Conventional warehouse operations routinely encounter critical bottlenecks:

  • Physical Discrepancies & Blind Spots: Disconnected spreadsheets and manual logs cause variances between reported software inventory and actual physical stock on warehouse shelves.
  • Lack of Granular Spatial Tracking: Standard inventory software tracks quantities by facility but fails to specify precise physical coordinates (Aisle, Rack, Bin), resulting in worker search latency and picking inefficiencies.
  • Stock Reservation & Allocation Confusion: Failing to differentiate between Total On-Hand, Reserved Stock for pending orders, and Damaged Stock leads to accidental overselling, delayed shipments, or unexpected stockouts.
  • Rigid Analytics & Delayed Action: Warehouse supervisors spend hours exporting static CSVs to determine reorder needs, lacking dynamic visibility into supplier lead times and warehouse stock health.
  • Siloed Financial & Procurement Workflows: Disconnected procurement systems delay restocking when purchase orders are manually communicated without integrated payment and supplier verification.
Key Solution Impact: Automation-CGI unifies physical location slotting, multi-level BOMs, ACID-compliant sales transactions, integrated Razorpay checkouts, and natural language AI query tools into one unified platform, eliminating data silos and operational latency.

5.1 Layered Backend Architecture Pattern

The backend strictly enforces the Controller-Service-Repository design pattern:

  • Controllers (e.g., orderController.js): Accept incoming HTTP requests, validate query parameters and JSON payloads, and return standardized JSON responses ({ success, data, message }).
  • Services (e.g., paymentService.js, aiService.js): Implement core business policies, mathematical validations, OTP email transmissions, and multi-step workflows.
  • Repositories (e.g., inventoryRepository.js): Direct data access layer executing optimized SQL queries with parameterized variables ($1, $2, ...) preventing SQL injection attacks.

6. DETAILED SYSTEM MODULES & FUNCTIONAL IMPLEMENTATION Section 6

6.1 Authentication & Multi-Tenant Access Control (RBAC)

User authentication is secured using JSON Web Tokens (JWT) and Bcrypt cryptographic hashing (salt rounds: 10). The registration and password reset workflows feature an integrated two-factor verification mechanism powered by otp-generator and nodemailer. Users receive a time-expiring 6-digit numeric OTP via SMTP. The client verifies the token before activating the user account or permitting password modification. Protected routes in React (ProtectedRoute.jsx) ensure unauthorized access is blocked.

6.2 Executive Dashboard & Live Business Intelligence

The executive dashboard provides high-level situational awareness through parallel database aggregations (Promise.all):

  • KPI Summary Cards: Real-time counts of Total Products, Low-Stock Warnings (items below reorder thresholds), Total Orders, Delivered Revenue, and Active Suppliers.
  • Warehouse Stock Health Heatmap: Visual matrix depicting inventory density and stock levels across multiple warehouse facilities.
  • Recent Activity & Status Badges: Chronological feed of recent customer orders and purchase orders with dynamic status tracking (PENDING, PROCESSING, SHIPPED, DELIVERED).

6.3 Granular Physical Inventory & Location Slotting

Unlike simplistic inventory trackers, Automation-CGI incorporates a 3-dimensional physical coordinate system: Aisle, Rack, and Bin linked through the locations table. The system calculates: 

available_quantity = quantity - COALESCE(reserved_quantity, 0) - COALESCE(damaged_quantity, 0)

Warehouse operators can rapidly adjust damaged quantities, update stock counts via modals, and inspect unit costs and selling prices for precise warehouse valuation.

6.4 Product Master Catalog & Bill of Materials (BOM)

The product module maintains SKU definitions, descriptions, barcodes, category classifications, and reorder levels. Additionally, the system supports assembly manufacturing through the Bill of Materials (BOM) engine. The bom and bom_items tables define the multi-component ingredients required to manufacture a composite finished product, complete with required quantities and unit measurements.

6.5 Sales Order Lifecycle & ACID Transactional Fulfillment

Orders encapsulate multi-line items associated with customers. Order creation executes within a strict PostgreSQL database transaction: 

BEGIN;
-- 1. Insert parent order record
INSERT INTO orders (customer_id, status, total_amount) VALUES ($1, 'PENDING', $2) RETURNING *;
-- 2. Insert line items in loop
INSERT INTO orderitems (order_id, product_id, quantity, unit_price, total_price) VALUES ...;
COMMIT; -- Or ROLLBACK on error

Upon order shipment, reserved quantities are cleared, physical stock is decremented, and revenue is recorded upon DELIVERED status.

6.6 Procurement & Purchase Order (PO) Management

When inventory levels drop below thresholds, procurement managers generate Purchase Orders mapped to approved suppliers. The PO lifecycle transitions through PENDING, APPROVED, RECEIVED, or CANCELLED, allowing seamless restocking into designated warehouse locations.

6.7 Supplier & Vendor Directory

Maintains complete vendor profiles including supplier names, contact emails, phone numbers, addresses, and transaction histories, ensuring reliable supply chain continuity.

7. ADVANCED INTELLIGENCE & HARDWARE INTEGRATIONS Section 7

6.8 Conversational Warehouse AI Assistant

Automation-CGI features a native, proprietary Warehouse AI Engine (/api/ai/chat) capable of answering real-time business queries without requiring SQL knowledge. The architecture implements a hybrid multi-tier intelligence pipeline:

Hybrid AI Execution Pipeline:
  1. Session Context Resolver: Recalls multi-turn context (e.g., user asks "What are my low stock items?" followed by "Show me the suppliers for those").
  2. Rule-Based Intent Analyzer: High-speed keyword and pattern scoring matching intents (INVENTORY_QUERY, LOW_STOCK, ORDER_STATUS, PRICE_CHECK, SUPPLIER_LOOKUP).
  3. LLM Fallback Router: Natural language prompts that do not match exact rule patterns are routed to a local or cloud LLM (Ollama / OpenAI) for zero-shot entity extraction.
  4. Domain Tool Dispatcher: Maps resolved intents to backend repositories (inventoryTool, orderTool, productTool) to retrieve actual live database records.
  5. Natural Language Generator: Formats the raw database rows into an intuitive, readable response returned to the frontend chat UI.

6.9 AI-Driven Dynamic Chart Generation

Inside the dashboard, users can request visualizations in natural language (e.g., "Show me a heatmap of warehouse stock" or "Generate an inventory flow sankey diagram"). The AIChart component parses the request and dynamically renders:

  • Heatmaps: Stock density across facilities.
  • Sankey Diagrams: Visual inventory flow and stock movements.
  • Scatter Plots & Radar Charts: Category distributions and stock balance metrics.
  • Gauge Health Meters: Real-time warehouse utilization and stock health indexes.

6.10 Optical Barcode & QR Code Scanning

Floor workers can perform instant stock lookups and physical inventory counts using the integrated camera scanner powered by html5-qrcode. Concurrently, the product catalog dynamically generates scannable QR codes using qrcode.react for printing onto physical warehouse bin labels.

6.11 Integrated Razorpay Payment Gateway

For B2B orders and customer checkouts, Automation-CGI integrates the Razorpay SDK. The server generates an authenticated order_id, prompts the interactive Razorpay checkout modal in React, and verifies payment authenticity on the server using cryptographic HMAC SHA-256 signature matching before marking orders as PAID.

6.12 Operational Reporting & Data Export Engine

The reports feature provides customizable filtering by date range, warehouse facility, and status. Reports can be immediately exported in two enterprise formats:

  • PDF Export: Rendered directly via jspdf and jspdf-autotable with formatted headers and page counters.
  • Excel Spreadsheet: Exported using xlsx and file-saver for corporate spreadsheet workflows.

6.13 Cross-Platform Native Desktop Client (Electron)

To accommodate rugged warehouse terminals that operate offline or in standalone kiosk mode, Automation-CGI is bundled into a native Windows executable via Electron. The electron.js main process automatically spawns the Node.js backend server in a background child process and mounts the production Vite build in a desktop window (1400x900).

Automation-CGI • Warehouse Management System Security, Reliability & Deployment

10. SECURITY, RELIABILITY & CONCURRENCY Section 10

10.1 Cryptographic & Application Security

  • Password Security: User credentials are protected using salted Bcrypt hashes before persistence, ensuring passwords are never stored in plaintext.
  • Stateless Authentication: Sensitive routes require an Authorization: Bearer <JWT> header verified via authMiddleware.js.
  • SQL Injection Elimination: All database queries in the repository tier strictly utilize parameterized placeholders ($1, $2, ...), precluding injection vectors.
  • Financial Signature Verification: Razorpay payments are verified on the backend by calculating HMAC-SHA256(order_id + "|" + payment_id, secret), preventing payment spoofing.

10.2 Concurrency & Transaction Management

Inventory allocation and multi-item orders are susceptible to race conditions. Automation-CGI guarantees atomicity by wrapping multi-row operations inside explicit database transactions (BEGIN ... COMMIT / ROLLBACK). Connection pooling through pg.Pool maintains up to 5 concurrent active connections with automated keepalive and 30-second idle timeouts.
